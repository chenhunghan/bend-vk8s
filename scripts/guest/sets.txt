# The role sets of the guest assets (docs/ref/footprint-decisions.md D1):
# a set's name, then the entries of out/assets/<ver>/bin it holds. Each is
# one read-only squashfs disk, <set>.img (scripts/guest/mksets.sh), and a
# VM mounts the sets of its role (src/cli/assets.bend Assets.role_sets)
# at /var/lib/vcluster/bin. kubeadm is in node: workers join with it, and
# control planes (which mount node too) make their PKI with it.
# kube-router (its network policy controller, src/guest/netpol.bend) is in
# node: every node's PID 1 runs it (NetworkPolicy is a parity feature).
# Optional sets, fetched and attached only when a cluster asks for them
# (docs/GOAL.md section 11; Assets.role_sets.v2): gvisor (runsc, its
# containerd shim, gvisor-bin/) on the nodes of a cluster made with
# --gvisor, which alone get the gvisor RuntimeClass; etcd (etcd, and
# etcdutl for an etcd restore) on the control plane of one made with
# --backing-store etcd. etcdctl stays in control-plane: kine's snapshot
# dump and restore use it too.
